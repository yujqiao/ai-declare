# AGENTS.md

## Commit Style

Use [semantic commit messages](https://www.conventionalcommits.org/):

```
<type>: <description>
```

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

Keep descriptions concise and imperative (e.g. "add" not "added").

## Spec Fidelity

Do not rephrase the [AI-DECLARATION.md spec](https://ai-declaration.md). Always use the exact wording verbatim.
